# Testes do Space Invaders

## Objetivo

A pasta `tests` é destinada à organização de testes do projeto Space Invaders, desenvolvido em Python com a biblioteca Pygame.

Os testes têm como objetivo verificar o funcionamento das principais mecânicas do jogo e ajudar a identificar possíveis erros durante o desenvolvimento.

## Funcionalidades que podem ser testadas

- **Pontuação:** verificar se os pontos são adicionados corretamente quando um alien é destruído.
- **Movimentação:** verificar o comportamento dos aliens e da nave.
- **Disparos:** verificar as colisões entre tiros, aliens, nave e barreiras.
- **Sistema de vidas:** verificar a perda de vidas e o encerramento da partida.
- **Progressão de fases:** verificar a mudança de dificuldade entre as três fases.
- **Barreiras:** verificar se as barreiras interagem corretamente com os aliens e os disparos.

## Situação atual

Este diretório está reservado para a implementação de testes automatizados. No momento, os testes ainda não foram implementados.

## Tecnologias utilizadas

- Python
- Pygame
